GUESSAi — GLOBAL RULES

این قوانین برای تمام بازی‌ها مشترک و LOCKED هستند؛ در پرامپت هر بازی تکرار یا تغییرشان نده.

• هر بازی Gameplay و UI مستقل خودش را دارد؛ Gameplay بازی‌ها را با هم قاطی یا کپی نکن.

• از Master Architecture موجود برای Wallet / XP / Level / Stamina / Reward / Progression استفاده کن؛ سیستم موازی نساز.

• Difficulty فعال: Easy / Medium / Hard. Extra-Hard و Max فعلاً Locked.

• هر راند = ۵ سؤال متوالی.

• ترکیب آیتم‌ها در هر راند Random است.

• هر بازی = ۵ Palette مستقل؛ Paletteهای بازی‌ها با هم متفاوت باشند و رنگ‌ها خوانا و مناسب موبایل باشند.

• زمان پاسخ هر سؤال برای Easy / Medium / Hard در Config همان بازی قابل تنظیم است.

• پاسخ درست = Correct؛ پاسخ غلط = Wrong؛ تعداد خطا و Game Over طبق Config اختصاصی همان بازی.

• هیچ Economy / XP / Coin / Stamina / Reward جدیدی داخل بازی نساز.

• در صورت پشتیبانی Gameplay، از Eventهای مشترک Streak / Combo / Super Combo استفاده کن و به Master Reward Engine بفرست؛ فرمول جدید نساز.

• نتیجه بازی از مسیر مشترک Settlement ثبت شود: Success / Failure / Game Over / Completion / Retry.

• اگر بازی به AI/API نیاز دارد، ابتدا سرویس‌ها و APIهای موجود پروژه را بررسی و همان‌ها را استفاده کن؛ API جدید فقط در صورت نیاز واقعی ساخته شود و چیزی حدس زده نشود.

• قبل از تغییر، Codebase و Master Architecture واقعی را بررسی کن.

• قوانین اختصاصی همان بازی فقط از پرامپت همان بازی گرفته شوند.

• هیچ مقدار، مکانیک یا قابلیتی که مشخص نشده اختراع نکن.

• فقط Gameplay همان بازی را پیاده‌سازی کن.

• در پایان Typecheck / Test / Build موجود را اجرا و نتیجه را گزارش کن.
