Speed Cards — روال ورود و شروع اولین بازی
روال شروع بازی Speed Cards را دقیقاً به شکل زیر پیاده‌سازی کن:
1. Category → Game
• بازیکن از صفحه Pick a Category، بازی Speed Cards را انتخاب می‌کند.
• مستقیماً وارد صفحه بازی Speed Cards شود.
2. آموزش کوتاه فقط در شروع
• فقط قبل از اولین راند، روی همان صفحه بازی یک آموزش کوتاه نمایش داده شود.
• Title: How to Play
• Text: Watch the cards carefully and remember their order.
• دکمه بزرگ: I'M READY
• این آموزش فقط یک‌بار در شروع بازی نمایش داده شود و قبل از هر راند تکرار نشود.
3. شروع بازی
بعد از زدن I'M READY:
3 → 2 → 1 → Start
• شمارش معکوس کوتاه و سریع باشد.
• سپس اولین راند شروع شود.
4. Difficulty
• از سیستم Difficulty و منطق فعلی پروژه استفاده کن.
• هیچ مقدار جدیدی برای Difficulty ایجاد نکن.
• تعداد کارت‌ها، سرعت، زمان نمایش و سایر پارامترها باید طبق مقادیر فعلی Speed Cards/Difficulty باشند.
• Economy، Stamina، Rewards یا تنظیمات نامرتبط را تغییر نده.
5. نمایش و برگرداندن کارت‌ها
• کارت‌ها دقیقاً طبق منطق فعلی Speed Cards نمایش داده شوند.
• بازیکن باید کارت‌ها را ببیند و جایگاه/هویت آن‌ها را به خاطر بسپارد.
• بعد از پایان زمان نمایش، کارت‌ها برگردند (Face Down).
• سپس مرحله سؤال شروع شود.
6. سؤال و انتخاب کارت
بعد از برگرداندن کارت‌ها، سؤال روی همان Game Screen نمایش داده شود، نه به‌صورت Popup.
مثال:
Which card was purple?
یا:
Select the purple card.
• هوش مصنوعی/منطق سؤال مشخص می‌کند کدام کارت باید پیدا شود.
• بازیکن باید خود کارت موردنظر را روی صفحه لمس کند.
• گزینه‌های متنی جداگانه مثل 1، 2، 3، 4 نمایش داده نشود.
• بازیکن مستقیماً خود کارت را انتخاب کند.
7. پاسخ درست
اگر بازیکن کارت درست را انتخاب کرد:
Correct
• Feedback کوتاه و سریع نمایش داده شود.
• سپس بدون برگشت به Category، مستقیماً وارد راند بعدی شود.
8. پاسخ غلط
اگر بازیکن کارت اشتباه را انتخاب کرد:
یک Popup نمایش داده شود:
WRONG
و دو گزینه داشته باشد:
CONTINUE — AdMob
EXIT — Category
• CONTINUE — AdMob: تبلیغ AdMob طبق سیستم فعلی پروژه اجرا شود و بعد از آن بازی ادامه پیدا کند.
• EXIT — Category: بازیکن از بازی خارج شده و به صفحه Pick a Category برگردد.
• از منطق فعلی AdMob پروژه استفاده کن و تنظیمات AdMob را تغییر نده.

مهم
• آموزش فقط یک‌بار قبل از اولین راند نمایش داده شود.
• قبل از هر راند آموزش نمایش داده نشود.
• سؤال روی همان Game Screen باشد، نه Popup.
• بازیکن باید خود کارت را لمس کند.
• جریان بازی سریع، روان و مناسب Mobile Casual Game باشد.
• از منطق، Difficulty، مقادیر و سیستم‌های فعلی Speed Cards استفاده کن.
• هیچ Economy، Stamina، Reward، Difficulty یا AdMob setting را بدون نیاز تغییر نده.
• هیچ سیستم جدیدی خارج از این Flow ایجاد نکن.
