🧾 FINAL DEVELOPMENT RULES (MUST FOLLOW)

IMPORTANT:

1. All economy values, prices, rewards, probabilities, unlock conditions, and cosmetic data must be configurable.
2. Nothing should be hardcoded.
3. The system must support adding new items, achievements, rewards, and events without changing core game logic.
4. Use a single config file (JSON) or database table as the source of truth.
5. All changes to the economy must be applied by updating the config file (no code changes).
