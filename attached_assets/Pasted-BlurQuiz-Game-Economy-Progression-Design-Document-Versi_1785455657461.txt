BlurQuiz — Game Economy & Progression Design Document
Version 1.0 — Production Implementation Specification
Purpose
This document is the single source of truth for BlurQuiz economy, progression, rewards, monetization, and retention systems.
The goal is to create a healthy long-term mobile game economy where:
• Players feel constant progress.
• Casual players are not left behind.
• Hardcore players have long-term goals.
• Monetization exists without Pay-to-Win.
• Progression feels rewarding, achievable, and enjoyable.
Do not modify economy values without balance testing.
1. Core Game Loop
The player loop:
• Start game
• Answer 20 blurred image questions
• Earn: 
• XP
• Coins
• Achievements
• Progress toward rewards
• Level up
• Unlock cosmetics/features
• Return for daily missions and challenges
The game should encourage daily play without creating frustration.

4. Combo System
Combo rewards consecutive correct answers.
StreakBonus XP3-4 answers+5 XP/question5-7 answers+10 XP/question8-11 answers+20 XP/question12+ answers+30 XP/question 
Rules:
• Combo resets after wrong answer.
• Bonuses do not stack.
• Maximum bonus is +30 XP/question.

12. Premium System
Premium must provide convenience, not advantage.
BlurPass Subscription
Price:
$3.99/month
Benefits:
• Remove ads
• 2x daily login coins
• Exclusive cosmetics
• Monthly premium category
• Extra missions
• Premium badge
No:
• Answer advantages
• Higher score bonuses

13. Advertisement System
Ads must never interrupt gameplay.
Interstitial Ads
Rules:
• Never during questions
• Never first launch
• Never tutorial
Show:
After every 3 completed games.
Maximum:
5 ads/session
Rewarded Ads
Available:
• Free coins
• Extra hints
• Double XP
Limit:
5/day free users
10/day premium users

18. Anti Farming Rules
Implement:
• No XP from repeated identical question sets within 1 hour.
• Daily XP cap:
10000 XP/day.
• Server-side tracking.
19. Implementation Requirements
Before UI design:
Developer must implement:
• XP calculation
• Level calculation
• Coin wallet
• Reward claiming
• Shop inventory system
• Premium state
• Daily missions
• Achievement tracking
All systems must be data-driven.
Do not hardcode rewards inside UI files.
Use configuration files/database tables.
Final Design Goal
BlurQuiz should feel:
• Fun
• Fair
• Rewarding
• Addictive in a healthy way
• Respectful of player time
The player should always feel:
"I am making progress."
Never:
"I can never finish this game.
