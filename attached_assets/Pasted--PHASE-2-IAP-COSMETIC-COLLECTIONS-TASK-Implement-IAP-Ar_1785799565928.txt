2. Purchase Flow

After Successful Purchase:

1. Verify transaction with platform.
2. Grant reward (gems or pass).
3. Save purchase history in database.
4. Prevent duplicate rewards.

Database Schema:

```json
{
  "transactionId": "unique",
  "productId": "product_123",
  "date": "timestamp",
  "status": "completed"
}
```
